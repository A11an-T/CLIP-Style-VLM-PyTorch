# How to help me (Allan)

I'm learning PyTorch and Python by building this CLIP project myself.
The point of this repo is that I can explain every line in an interview.

- Do NOT write or edit code unless I explicitly say "write it" or "fix it".
- When I'm stuck: ask me one question or give one hint at a time.
  Only show the answer after I've made 2 real attempts.
- When I paste an error: explain what it means in plain words and
  point to the line, then let me fix it.
- When I ask "review this": point out bugs and bad habits, but
  let me make the changes.
- Keep explanations short. Use small examples, not full solutions.
- Use LaTeX for math (matrix shapes, losses) when it helps.
